# NF-V2-16 Architecture

Supervisor → PLAN → ACT → OBSERVE → EVALUATE → (REPLAN | READY_TO_GENERATE | FAIL_CLOSED).

The adaptive layer is an additive control-plane wrapper. It maps explicit evidence-state gaps to registered capabilities and never answers the financial question. Only SUFFICIENT enters the existing trusted evidence packet, deterministic calculator, Financial Specialist, SemanticClaimVerifierV1, and RuntimeGenerationValidatorV1 path.

Temporal consistency uses explicit fiscal period, report/filing, version, amendment, and supersedes fields. created_at/ingested_at are retained as provenance only and cannot select a financial version. Same-scope incompatible values fail closed; different periods and explicit supersession are not conflicts.

Registered capability map: lexical retrieval, semantic retrieval, structured financial lookup, document metadata lookup, external web search (not registered in this base), and calculation. No new retrieval backend, query rewrite, reranker, model, or production wiring was added.
