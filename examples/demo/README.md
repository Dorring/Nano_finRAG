# Demo 示例数据

本目录包含用于系统演示的 synthetic 合成示例数据（synthetic demo data）。

## 免责声明

**这些问题是纯粹合成的演示示例，不基于任何真实公司的财务数据。** 其中提到的数字（如 2024、2025 年度收入等）均为虚构，仅用于展示系统的文档问答、确定性计算和不可回答问题处理能力。

在真实的演示场景中，应使用实际上传的财务文档来替换这些示例数据。

## 文件说明

- `demo-questions.json` — 三类演示问题：文档问答、财务计算、不可回答
- `expected-behaviors.json` — 每类问题对应的预期系统行为与验证要求
